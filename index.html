NAI · PROMPT TOOL

Prompt → JSON ✦

한국어 설명과 영문 프롬프트를 함께 넣어도 영문 프롬프트만 추출해 장면별 JSON으로 정리해요. 모든 작업은 내 브라우저에서 처리됩니다.

① 원본 입력

`### 01 · 제목` + ```text 코드블록``` 형식에 최적화. 코드블록이 없어도 영어 태그 줄을 추출할 수 있어요.

② 변환 설정

출력 형식: {"version":1,"scenes":[{"name":"...","prompt":"...","negativePrompt":"","width":832,"height":1216}]}

③ 추출된 장면 0

변환하면 장면이 여기에 나타나요. 제목을 직접 수정하거나 장면을 삭제할 수도 있어요.
